选择题第4题 · A、B、C 三个选项的反例图

题目：下列说法正确的是（ ）—— 正确答案是 D（对角线互相垂直平分的四边形是菱形）。下面用图说明 A、B、C 为什么错。

反例 A：四条边相等的四边形不一定是正方形

四条边相等 → 只能得到菱形。再加上"有一个角是直角"或"对角线相等"才是正方形。

反例 B：对角线相等的四边形不一定是矩形

正确结论：对角线相等的平行四边形才是矩形。少了"平行四边形"这个前提，等腰梯形就是反例。

反例 C：有一组对边相等的平行四边形不一定是菱形

平行四边形的对边本来就相等，所以"一组对边相等"是废话，满足条件的普通平行四边形遍地都是。要判菱形需"一组邻边相等"或"对角线互相垂直"。

选择题第7题 · 矩形法求 MN 的最小值

题意：Rt△ABC 中，∠A=90°，AB=3，AC=4，D 是斜边 BC 上的动点，DM⊥AB，DN⊥AC。求 MN 的最小值。

发现规律：∠DMA=∠DNA=∠A=90° → 四边形 DMAN 有三个直角，是矩形 → MN = AD！所以求 MN 最小值就变成求"点 A 到直线 BC 的最短距离"——垂线段最短。

计算：S△ABC = ½·AB·AC = ½·BC·ADmin → ADmin = (3×4)/5 = 12/5。故选 A。

选择题第8题 · 两次相似求 DG/CG

题意：▱ABCD 中，E 是 BC 中点，BG 交 AE 于 F、交 CD 于 G。已知 AF:FE = 3:1，求 DG:CG。

思路（两次相似）：① 延长 AD 交 BG 延长线于 H，由 AH∥BE 得 △AHF∽△EBF，AH = 3BE；又 AD = BC = 2BE，所以 DH = BE。② 由 DH∥CB 得 △DGH∽△CGB，故 DG/CG = DH/BC = BE/(2BE) = 1/2。故选 A。

填空题第11题 · 小孔成像中的相似三角形

填空题第12题 · 装裱问题列方程

题意：原作品长 60cm、宽 24cm。左右边宽相等（设为 x），天头长与地头长相等，右边宽 : 天头长 = 1 : 5，装裱后总面积 2240cm²。列方程。

展开：(60+10x)(24+2x) = 2240 → 20x² + 360x + 1440 = 2240 → x² + 18x − 40 = 0。
求根：x = (−18 + √(324+160))/2 = (−18+22)/2 = 2（负根 −20 舍去）。
检验：长 60+10×2 = 80，宽 24+2×2 = 28，80×28 = 2240 ✓
列方程的关键：用 x 把所有边长都表示出来 —— 右边宽 x → 天头长 5x → 装裱后总长 60+2·5x、总宽 24+2x → 面积相乘等于 2240。
